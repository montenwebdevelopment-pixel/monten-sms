Monten SMS Android debug APK
============================

Install `monten-sms-debug.apk` on an Android phone for testing.

1. Download the APK to your phone.
2. Open it and allow installation from this source if Android asks.
3. Confirm the installation and launch MONTEN SMS.

This is a debug-signed test build, not a Play Store release. Android will not
allow it to update an installation signed with a different key. Installations
from this build may need to be removed before installing a differently signed
release. Do not share the debug APK as a production release.
